# TikTok Video Studio (Android)

تطبيق أندرويد (Kotlin + Jetpack Compose + Media3 Transformer) لتجهيز الفيديوهات لـ TikTok. واجهة عربية RTL.

## إضافات جديدة (مدموجة من TikEdit)
- **قص السكتات تلقائيًا** (مع حساسية)، بيشتغل جوه مدى القص الزمني ومع «كل المحدد».
- **كابشن عربي تلقائي** من غير خلفية (ظل غامق) مع **تمييز الكلمة الحالية**. بيحتاج مفتاح OpenAI بتحطه من شاشة التجهيز (بيتحفظ على جهازك بس، من غير أي سيرفر).
- **هوك نصي** في أول ثواني بحركة ظهور واختفاء.
- لو الكابشن فشل أو مفيش مفتاح، الفيديو بيتصدّر عادي والسبب بيظهر في تقرير الفحص.

## المتطلبات
- Android Studio **Ladybug (2024.2.1) أو أحدث** (بييجي معاه JDK 17).
- إنترنت في أول Sync لتحميل Gradle والمكتبات.
- هاتف أو محاكي **Android 8.1 (API 27) أو أعلى**. الأفضل هاتف حقيقي (الترميز بالـ hardware).

## التشغيل
1. فك الضغط، ثم Android Studio ← **Open** ← اختار مجلد `TikTokStudio` (اللي فيه settings.gradle.kts).
2. استنى **Gradle Sync**. لو سأل عن تحديث Gradle/AGP اقبل أو ابعت لي الرسالة.
3. وصّل الهاتف (Developer options ← USB debugging) واضغط ▶ Run.
4. لـ APK: **Build ← Build Bundle(s) / APK(s) ← Build APK(s)**.
   الملف في: `app/build/outputs/apk/debug/app-debug.apk` (نسخة debug بتتثبّت مباشرة).

## هيكل الملفات (app/src/main/java/com/tiktokstudio/app)
- MainActivity.kt: التنقل بين الشاشات + الصفحة الرئيسية + قائمة الفيديوهات
- VideoInfo.kt / VideosViewModel.kt: اختيار الفيديوهات وقراءة معلوماتها
- ExportSettings.kt: الإعدادات وخطة التصدير (المقاس، الجودة، القص، الدمج)
- EditorScreen.kt: شاشة التجهيز
- Watermark.kt / WatermarkScreen.kt: النص العربي والشعار والمعاينة والقوالب
- Exporter.kt: التصدير الفعلي (Media3) + فحص الناتج + الحفظ
- QueueManager.kt / ExportService.kt / Jobs.kt: الطابور والخدمة الأمامية وحفظ المهام
- QueueScreen.kt: الطابور والسجل والإعدادات
- SilenceDetector.kt / SmartEdit.kt / Captions.kt: قص السكتات والكابشن والهوك
- Analysis.kt / AnalysisScreen.kt: الفحص قبل المعالجة والمقارنة ومساعد الأصالة
- Verify.kt / Mp4Util.kt: فحص الملف الناتج ومسح الموقع

## لو حصل خطأ في البناء
ابعت نص الخطأ كامل (من تبويب Build في Android Studio).

## قائمة الاختبار على الهاتف (لازم تتعمل يدويًا)
- [ ] استيراد فيديو واحد وعدة فيديوهات، عمودي وأفقي
- [ ] تصدير 1080×1920 و720×1280، ملء واحتواء، تحريك موضع القص
- [ ] ضغط (منخفضة/متوسطة/مرتفعة/حجم مستهدف) ومقارنة الحجم
- [ ] نص عربي (اتصال الحروف والاتجاه) + شعار PNG شفاف: المكان والحجم في الناتج = المعاينة
- [ ] تدوير الفيديو: اتجاه الناتج صحيح
- [ ] قص زمني + كتم الصوت + الصوت متزامن مع الصورة في الناتج
- [ ] فيديو CFR وفيديو VFR (جرّب بدون وبـ «تثبيت CFR») وقارن عدد الإطارات والمدة
- [ ] طابور من 3 فيديوهات مع قفل الشاشة / الخروج من التطبيق
- [ ] إلغاء في نص التصدير: مفيش ملف ناقص في مجلد الحفظ
- [ ] غلق التطبيق بالقوة أثناء التصدير ثم «استئناف المهام»
- [ ] فيديو كبير (1GB+) / 4K بدون انهيار الذاكرة
- [ ] مساحة قليلة: رسالة خطأ مفهومة
- [ ] تشغيل الناتج في المعرض وفي مشغل تاني (VLC مثلًا) وفي TikTok
- [ ] مسح الموقع: فيديو مصوّر بالكاميرا مع GPS، والتقرير يأكد إنه اتمسح
- [ ] فيديو HDR (معروف إن الألوان ممكن تتغير)

## حدود معروفة
- ترميز H.264 + AAC بس.
- مفيش تحويل HDR→SDR.
- الفحص البصري (شعار/أشرطة/QR) تقديري.
- الاستئناف بعد غلق التطبيق بيبدأ المهمة من الأول.
- قرار التوصية في TikTok بيرجع للمنصة، ومفيش أداة بتضمنه.

## بناء APK على GitHub (من غير Android Studio)
1. ارفع محتويات المجلد ده (مش المجلد نفسه) على repository جديد في GitHub.
2. افتح تبويب **Actions** ← **Build APK** وانتظر ✓ (حوالي 5 إلى 10 دقايق).
3. افتح التشغيلة الناجحة ونزّل **app-debug-apk** من قسم Artifacts. هيتحمّل كـ zip فيه app-debug.apk.
4. لو فشل: نزّل **build-log** وابعته.
